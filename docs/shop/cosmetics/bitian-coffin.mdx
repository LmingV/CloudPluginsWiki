## 棺上有什么

| 部位 | 说明 |
| --- | --- |
| ❄️ 冰蓝魂纹 | 棺面中央一道冰蓝魂火，自顶端锁扣直贯棺底，枝脉如霜向两侧蔓延，**32 帧动态贴图**，火光一刻不停 |
| ⛓️ 封棺铁链 | 横锁棺身、侧垂双柱，随棺体晃动自然摆荡 |
| 🏮 符幡与魂灯 | 两侧符幡随风翻卷，冰蓝魂灯悬挂柱侧 |
| 🗼 双塔立柱 | 两根哥特尖柱夹棺而立，撑起整口棺的气势 |
| 💫 天环 | 八角天环悬于棺顶，垂落冰棱，随棺浮沉 |
| 🌬️ 寒气与星辰 | 冰蓝气流绕棺游走，碎星忽明忽灭 |

## 双版本

| 版本 | 模型 ID | 说明 |
| --- | --- | --- |
| 直立版 | `bitian_coffin` | 棺身笔直，正面完整展示魂纹 |
| 斜背版 | `bitian_coffin_diagonal` | 40° 斜背，侧身行走更有压迫感 |

两个版本动画完全一致，方块数 606、骨骼 170，一个服务器可以同时上架两种背法。

:::caution 请保留英文文件名
ModelEngine 以文件名作为模型 ID，请保持 `bitian_coffin.bbmodel`、`bitian_coffin_diagonal.bbmodel` 原名，**不要改成中文**。
:::

## 动画

| 动画名称 | 类型 | 说明 |
| --- | --- | --- |
| `idle` | 循环 · 24 秒 | 棺体沉浮呼吸、棺中异动挣扎、符幡与铁链晃动、天环浮动、寒气环绕、星辰明灭 |

- 全部动画为**数值关键帧**，不依赖 Blockbench Molang 运算式，导入 ModelEngine 后动作与预览一致；
- 魂火贴图附带 `mcmeta`，32 帧共 40 tick 循环，资源包生成后即可直接播放。

:::note 已实测
已在 Purpur 1.21.4 + ModelEngine R4.0.9 完成模型导入、资源包生成与贴图动画检查。
:::

## 搭配云时装使用

放入 `plugins/ModelEngine/blueprints/` 并执行 `/meg reload`，重新生成并下发资源包后，在[云时装](/docs/cosmetics)中加入：

```yaml title="cosmetics/eternal.yml"
bitian_coffin:
  type: meg
  name: '<gradient:#E8F4FF:#3F8CFF>[天葬]</gradient> 避天棺'
  model: bitian_coffin            # 斜背版改成 bitian_coffin_diagonal
  scale: 1.0                      # 按服务器需要调整大小
  follow-rotation: true
  animations:
    idle: idle
```

也可以不用云时装，搭配 MythicMobs / 其他 ModelEngine 插件使用。

:::tip 出现紫黑缺图？
只替换 `.bbmodel` 而沿用旧资源包时会出现紫黑贴图，请重新生成 ModelEngine 资源包并让玩家重新下载。
:::
