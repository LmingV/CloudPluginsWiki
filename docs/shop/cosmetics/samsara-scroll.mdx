## 搭配云时装使用

放入 `plugins/ModelEngine/blueprints/` 并执行 `/meg reload` 后，在[云时装](/docs/cosmetics)中加入：

```yaml title="cosmetics/eternal.yml"
samsara_scroll:
  type: meg
  name: '<gradient:#FFF7C2:#69ECFF>[永恒]</gradient> 轮回生死轴'
  model: your_model_id          # 改成导入后的 ModelEngine 模型 ID
  scale: 1.8
  follow-rotation: true
  animations:
    idle: living_scroll_loop
  totem: true                    # 可选：穿戴时获得不死图腾保命
  totem-cooldown: 300
  totem-health: 8
```

也可以不用云时装，搭配 MythicMobs / 其他 ModelEngine 插件使用。
