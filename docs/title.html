✦ CloudTitle 云称号

适用核心Paper | Purpur | Folia适用版本1.20 – 26.x推荐前置PlaceholderAPI数据库SQLite | MySQL | MariaDB购买价格45R最新版本v1.0.0

把一组图片放进文件夹，它就是一个会动的称号。 不用写 mcmeta、不用手动做资源包：按文件名顺序自动播放，GIF 自动拆帧，资源包一键生成并合并进 ItemsAdder / CraftEngine / Nexo。

为什么选择云称号​

很多称号插件只能显示文字，或者要求你手写 .mcmeta 动画、自己拼资源包、自己分配字符。 云称号把这些全部自动化，并且把动画的计算量压到几乎为零 —— 动态称号不会因为人多而拖慢服务器。

🎞️

序列帧动画

a1.png、a2.png … a10.png 按数字顺序播放并循环；只放一张就是静态称号；直接放 GIF 也行。

📐

大图 + 小图

头顶用大图 %clt_use%，TAB / 记分板用小图 %clt_use_small%。小图可单独绘制，也可自动缩小。

📦

资源包自动生成

像 ModelEngine 一样生成资源包，自动同步到 ItemsAdder、CraftEngine、Nexo，不占用它们的字符区。

⚡

动画几乎零开销

每一帧的字符在生成资源包时就已算好，变量只是按时钟取一个字符串，每 tick 查询也不增加负担。

🛒

完整获取玩法

商店（金币 / 点券 / 物品任意组合）、称号卡、活动发放、限时称号自动到期，全部记入操作日志。

🌐

跨服即时同步

多个分流共用 MySQL 时，在大厅给予的称号几秒内出现在玩家所在的生存服，不用重新进服。

20fps 最高播放速度
10个 PlaceholderAPI 变量
3种资源包合并目标
3种货币可组合定价
150+项自动化与实机测试

功能一览​

模块能做什么
称号动画文件夹内 PNG 按文件名数字顺序播放；单张图 = 静态称号；GIF 自动拆帧并沿用帧延迟；每个称号可单独设 fps（1 – 20）
两种尺寸大图 %clt_use%（头顶 / 名称）与小图 %clt_use_small%（TAB / 记分板），各自可设高度、垂直位置与偏移
静态版本%clt_use_static% / %clt_use_small_static% 只显示首帧，适合聊天室与不希望闪动的位置
资源包自动生成文件夹与 zip，字符表持久保存（重载后字符不变），可合并进 ItemsAdder / CraftEngine / Nexo
称号仓库/clt open 查看全部称号、佩戴与卸下，未拥有的称号显示获取方式
称号商店金币（Vault）、点券（PlayerPoints）、物品（原版 / MMOItems / ItemsAdder / CraftEngine / Nexo）任意组合，缺一样就什么都不扣
称号卡右键使用获得称号；已永久拥有时不消耗；重载后背包里的旧卡自动更新名称与说明
限时称号任意时长（7d12h），重复获得自动续期，到期自动卸下并提示
属性加成接入 MythicLib / MMOItems 属性，可选「佩戴才生效」或「拥有即生效」；属性显示名称在 stats.yml 自定义
管理/clt view <玩家> 打开玩家的称号仓库直接给予 / 收回；/clt log 查看操作日志
展示/clt showcase <玩家> 查看别人拥有的称号（只读）
数据SQLite 单服，或 MySQL 8 / MariaDB 多服共享并即时同步
开发者公开 API 与事件（获得 / 失去 / 佩戴），聊天插件可直接取得称号字符与悬停文本
头顶称号怎么显示？

云称号不自己渲染头顶文字，只提供变量。把 %clt_use% 填进你正在使用的头顶 / 名称插件（例如 TAB 的 nametag、DecentHolograms 等）即可，完全不和现有插件冲突。详见变量。
