# CloudChat

CloudChat 是面向 Minecraft 服务器的聊天体验插件，负责把消息展示、频道组织与权限策略集中管理。它适合需要更清晰社交边界、更多运营玩法的大厅与生存服。

## 能力概览

| 模块 | 说明 |
| --- | --- |
| 消息格式 | 统一处理前缀、颜色、等级与展示信息 |
| 频道组织 | 将全局、局部或运营频道拆分管理 |
| 权限策略 | 为不同身份配置发言、管理与特殊格式权限 |
| 管理工具 | 便于排查消息、调整规则与维护聊天秩序 |

## 推荐上线流程

1. 安装插件并确认服务端成功加载。
2. 先用默认配置验证消息链路，再逐步调整格式与频道。
3. 为管理组配置聊天管理权限，为普通玩家配置基础使用权限。
4. 用多个测试账号验证频道可见范围、颜色格式和异常消息处理。

## 配置原则

聊天格式建议保持短而清晰：身份信息负责建立信任，频道信息负责建立边界，正文区域留给玩家交流。大型服务器可以为公告、交易、组队等场景建立独立频道，减少全局聊天噪声。

> 不同版本的命令前缀、权限节点和配置键可能存在差异，请以安装包内的默认配置与版本说明为准。
