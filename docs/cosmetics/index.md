# CloudCosmetics

CloudCosmetics 是 CloudPlugins 云系列中的外观与个性化展示插件。它把外观内容、称号和玩家展示统一到可维护的配置体系中，让服主可以持续扩展内容，而不必反复修改核心逻辑。

## 能力概览

| 模块 | 说明 |
| --- | --- |
| 外观管理 | 统一维护可用外观、展示名称与解锁条件 |
| 玩家展示 | 为大厅、菜单和个人资料提供一致的展示信息 |
| 权限控制 | 使用权限节点区分管理员、玩家与活动内容 |
| 配置驱动 | 内容与逻辑分离，便于迁移、备份与版本升级 |

## 推荐配置流程

1. 完成插件安装并确认服务端正常加载。
2. 先备份默认配置，再按服务器定位调整展示内容。
3. 为管理人员分配管理权限，为玩家开放使用权限。
4. 使用测试账号验证解锁、展示和重载流程。

## 使用建议

外观内容建议按主题或活动建立清晰的命名规则，并保留一份版本化配置备份。涉及付费或限定内容时，请同时写清解锁条件与有效期，减少玩家理解成本。

> 具体配置键与权限节点以你安装的插件版本为准。若当前版本尚未提供某项能力，请通过 GitHub 提交需求。
