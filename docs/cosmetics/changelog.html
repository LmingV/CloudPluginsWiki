更新记录

每个版本的更新内容与发布日期。升级方式见安装与升级。

3.0 原生背包

3.0 起支持 ItemsAdder / CraftEngine 原生背包（type: backpack），贴身跟随、转身同步，可与帽子等时装同时穿戴。配置见原生背包。

2.10.8 多件穿戴

2.10.8 起可以让玩家同时穿戴多件时装（翅膀 + 头饰 + 光环……），默认仍为一次一件。开启方式见多件穿戴。

v3.1.0最新2026-09-26

原生背包体验升级

  • 优化背包转向更跟手：快速转身后立即与玩家朝向对齐
  • 优化区域保护更友好：在禁止生成实体的区域（如 WorldGuard 保护区）背包会自动暂停显示，限制解除后自动恢复，并在控制台提示
  • 优化背包仅作为外观显示，不会掉落
  • 兼容直接替换 JAR 并完整重启，不需要修改任何配置或数据
v3.02026-09-26

CE / IA 原生背包

  • 新增新增原生背包 type: backpack：直接使用 ItemsAdder / CraftEngine 的背包物品，贴身跟随、转身同步，不占用玩家的头盔或副手
  • 新增背包配置简单：backpack.source 与 backpack.item 两行即可
  • 新增CE / IA 帽子（type: equipment、slot: HEAD）可与原生背包同时穿戴
  • 优化背包的移动与转向同步：走、跑、转身都紧贴玩家
  • 兼容原有 BODY 时装配置保持不变；原生背包的位置与大小由模型资源包决定
v2.10.82026-09-26

可设置的多件穿戴

  • 新增新增两种穿戴模式：equipment.mode: single（全身一件）/ per-category（每个分类分别穿戴）
  • 新增分类以 cosmetics/ 内的 YAML 文件名为准；body、meg、equipment 只是渲染方式，不再作为「同类型只能一件」的限制
  • 新增支持 BODY + MEG + HEAD 同穿，以及多件 MEG 同穿；同一模型也能由不同时装配置分别挂载
  • 新增menus/categories.yml 每个分类可设 max-equipped（默认 1，0 禁止穿戴）；分类满额时替换该分类最早穿戴的一件
  • 新增equipment.max-equipped 全身总上限，超出时拒绝新增并保留原穿搭
  • 新增原生装备槽冲突检查 equipment.slot-conflict：replace 替换旧时装 / deny 拒绝新时装
  • 新增新增时装字段 equip-group：不同分类的整套模型或配件互斥，同组只保留新穿戴的一件
  • 优化整合多个模型的挂载清单，BODY / MEG 不再互相覆盖；原生 HEAD 与 OFF_HAND 外观状态独立管理
  • 优化点击衣橱中已穿戴的项目只卸下该件；「卸下」按钮仍为全部卸下
  • 优化多件穿搭按顺序保存，重登后恢复；自动沿用旧版单件数据
  • 优化多件图腾时装共用玩家冷却，采用最早穿戴的图腾时装规则，切换时装不会重置冷却
  • 修复数据加载中 / 加载失败时阻止穿戴变更，避免覆盖尚未成功读取的数据
  • 兼容默认 mode: single，旧服升级不会突然开启多件；切回 single 时保留最后穿戴的一件。属性仍按已拥有时装计算，同穿多件不会重复加成
v2.10.72026-09-26

修复 BODY 闪烁与上下跳动

  • 修复修复 BODY 已挂到玩家身上，却仍收到独立移动、传送与位置同步封包，导致模型突然掉下去又回来的问题
  • 优化已挂载的 BODY 由客户端处理乘客位置，保留转向更新；服务端仍维持实体位置与追踪范围
  • 优化挂载清单不变时不再重复发送，减少反复挂载引发的不稳定
  • 修复补强登录与实体生成的时序，修复挂载封包早于模型生成而失效的情况
  • 修复修正销毁、重登、切换可见性及跨世界后的挂载状态清理与恢复
  • 兼容适用原版、ItemsAdder 与 CraftEngine 来源的 BODY 时装
v2.10.62026-09-26

IA / CE 跟随与装备外观改善

  • 优化BODY 在玩家移动、转向时直接更新朝向，移除额外的展示插值延迟，改善跑动时模型落后的感觉
  • 优化改善 ItemsAdder / CraftEngine 自定义物品读取，保留来源插件生成的完整物品数据
  • 优化改善 equipment 原生装备外观封包；帽子可用 HEAD，适合副手姿势的素材可用 OFF_HAND
  • 修复真实主手 / 副手物品优先显示，清空后恢复时装，不会遮住盾牌、图腾或工具
  • 修复创造模式隐藏本人的虚拟装备，避免展示物品进入创造背包；其他玩家仍可看到，回到生存模式后恢复
  • 新增找不到 MEG 模型或自定义物品时给出提示；不支持的装备槽会在加载时警告
v2.10.52026-09-25

MEG 偏移方向修正 · CE BODY 显示模式

  • 修复MEG XYZ 偏移方向修正：ModelEngine 会从骨骼位置减去挂载补偿值，之前把偏移加进补偿值导致显示方向相反。现在正 Y 向上，X / Z 按玩家朝向换算（玩家与 NPC 通用）
  • 兼容⚠ 升级前为了抵消反向而调整过的 MEG offset，升级后需要把 X / Y / Z 的正负号反过来
  • 新增CE BODY 新增 body.transform 显示模式：CraftEngine 来源默认 NONE，可选 HEAD、FIXED、GUI、GROUND 等；body.anchor 控制位置，两者互相独立
  • 兼容原版与 ItemsAdder 来源未指定 transform 时仍使用 HEAD，旧配置外观不变
  • 修复BODY 移动时逐 tick 同步展示实体位置，不再等距离超过 2 格才补位；正常情况仍由乘客挂载跟随
  • 优化包含 2.10.3 / 2.10.4 的 R4.1 挂载注册与登录挂载补发修复
v2.10.42026-09-25

登录挂载重发（测试版，已并入 2.10.5）

  • 修复R4.1 下同时标记外层「穿戴者 → 模型」挂载，让 ModelEngine 重新发送挂载封包
  • 修复生成、重新追踪与显示后于 2 / 10 / 30 tick 补发挂载，只对仍在线且可见的观察者重试，模型移除后停止
